<h1>Prototipo Control</h1>
  <p>
    Este proyecto se realizó como una evaluación para la universidad. El propósito era crear un mando virtual interactuable, el cual pueda controlar alguna máquina a elección; en este caso se trata de un robot, el cual puede moverse, volar, agarrar otros bloques y modificar el tamaño de los bloques.
  </p>

<h2>Funcionamiento</h2>  
  <p>
    Primero, el control inicia apagado en la escena, por lo que se requiere una batería para encenderlo.
  </p>

  <p>
    Internamente, lo que sucede es que, al colocar o quitar la batería en el espacio de atrás del mando, llama a uno de los dos métodos, los cuales, dependiendo de cuál sea el caso, todos los componentes (scripts) que contiene el mando se activarán o desactivarán.
